# Template origin

This personal site is based on [al-folio](https://github.com/alshedivat/al-folio), using upstream starter revision `40c06007dab344970b681ba63b2241b1a8209ec1` and the pinned `al_folio_core` version in `Gemfile`.

The upstream MIT license is retained in `LICENSE`. Site-specific changes are personal-site overrides: the header, footer, project gallery, and final Sass layer. The core al-folio default layout and theme runtime remain in use. Upstream example publications, posts, news, teaching, and projects are excluded.
